Units are whatever you count on the shelf: reams, cans, pairs. Scales with says how an item is used: Everyone, per week (snacks: amount × everyone × weeks), Team, one each (teammates' own slippers: amount × headcount, so a new hire gets a pair), or Guests, one each (guest slippers: amount × guests). Safety stock is added to all three. A fixed target overrides them; use it for one-time purchases like racks and bins, which order once and stop. On order is what's already been bought but hasn't arrived, so it never gets ordered twice. "Log as placed" fills it in for you, and "Mark arrived" in the Order log moves it onto the shelf.
